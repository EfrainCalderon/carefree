# Carefree

Carefree helps people, especially men 35–55 who haven’t seen a doctor in years, find the preventive care their insurance already covers at $0, then leave with a one-page visit plan.

This Storybook shows every component the live app uses, with the same code and the same theme.

## How it fits together

- **Tokens** live in `tokens/tokens.json` (managed in Figma with Tokens Studio) and build into `src/tokens.css` as `--cf-*` variables.
- **Primitives** are [shadcn/ui](https://ui.shadcn.com) components in `src/components/ui/`, themed by those tokens.
- **Carefree components** in `src/components/chat/` are built from the primitives: the questions (one per screen), the plan page (visit cards, the first step, tap-to-define terms), the checklist view, the paper layout, email, and feedback. The app (`src/app/App.jsx`) only composes them.
- **Stories** sit next to each component, so the app and Storybook always render the same code.

## Principles

- Visits, not benefits: organize around the appointments a person books.
- Calm, one color: greens only, no grade badges or traffic-light colors.
- Plain words, and every answer visibly changes the plan.
- Show value before asking anything personal: three answers to a plan, more questions offered after.
- One option per different outcome. If two answers lead to the same plan, they are one answer.
- Say each thing once, and never describe the interface to the person using it.
- One dark green block per page, on the thing to do next.

Sample data comes from the real recommendations, using the app’s own plan logic for Marcus (47, insured through work), Linda (67, Medicare) and Sam (29, no insurance).
